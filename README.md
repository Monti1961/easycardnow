# EasyCardNow

Static website for EasyCardNow.

## Deploy

This is a static site. Upload the repository to GitHub and connect it to Cloudflare Pages. No build command is required.

## Important

Do not add unsupported provider claims, user counts, transaction volumes, margins, licenses or security guarantees. Update legal pages with the actual operating entity, contact details, jurisdiction and applicable provider information before public launch.


## Languages
The site includes English and Russian versions. Russian pages live under `/ru/` and use hreflang annotations. The primary CTA links to the EasyCardNow Telegram bot: https://t.me/easycardnow_bot.
